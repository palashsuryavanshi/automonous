# Automonous - Release Notes

## v0.5 - Alpha Release

- First public alpha release of Automonous.
- Includes the encrypted credential vault for GST, Income Tax, and TDS portals.
- Playwright-based login automation using system Chrome/Edge.
- PDF utilities: PDF Merger and PDF to Word (OCR).
- 2A/2B or R1 with Books Reconciliation Tool (Excel).
- Light-mode web UI with emerald navigation and high-quality server console.
- All processing runs locally; no credential data is sent externally.

## v0.3 - Rebranding release

- Rebranded the product from CA Forge to Automonous.
- Updated application name, window/console titles, installer names, and documentation.
- GitHub repository and release assets published under the Automonous name.
- No functional changes to the credential vault, portal automation, or utilities.
